Dolby Lake Hardware Support

Created specifically for touring audio engineers and venues operating Dolby Lake Processors (DLP), Lake Mesa Quad EQ, LM 26, LM 44, and Lab.gruppen PLM Series amplifiers without relying on obsolete Windows 7 machines.

🪟 Native Modern Windowed Mode

Replaces the legacy, crash-prone DirectDraw exclusive fullscreen engine. Minimizing, maximizing, and resizing are smooth and instant on Windows 10/11, macOS, and Linux without display lockups or white screens.

🌐 UDP 6004 & Network Interface Selection

Built-in network adapter selector allows direct binding to Dante subnets or dedicated processor control networks. Eliminates ghost audio meter movement when offline.

⚡ Decompiled Parameter Accuracy

Parametric EQ curves, 28-band Graphic EQ (GEQ), LimiterMax thresholds, and crossover slopes conform 100% to real constants decompiled from original Lake DSP libraries.

Build locally using the included Makefile or trigger automated GitHub Releases across Windows, Linux, and macOS:

make package-all

# Create GitHub Release with compiled binaries
make github-release
